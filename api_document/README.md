# CAB System API Specifications

These OpenAPI 3.0.3 YAML specifications were generated by grouping endpoints according to the 11 Functional Requirement (FR) components in `srs.md`.

## Files
1. customer-management.yaml — FR-CM-01 to FR-CM-04
2. booking-management.yaml — FR-BK-01 to FR-BK-05
3. driver-management.yaml — FR-DM-01 to FR-DM-04
4. driver-matching-assignment.yaml — FR-MA-01 to FR-MA-06
5. trip-management.yaml — FR-TR-01 to FR-TR-05
6. fare-payment.yaml — FR-PM-01 to FR-PM-06
7. notification-management.yaml — FR-NT-01 to FR-NT-06
8. rating-trip-history.yaml — FR-RH-01 to FR-RH-03
9. operation-management.yaml — FR-OM-01 to FR-OM-07
10. reporting-monitoring.yaml — FR-RP-01 to FR-RP-05
11. authentication-access-control.yaml — FR-AC-01 to FR-AC-04

Notes:
- The SRS specifies functional requirements and business rules, but does not define exact REST endpoint paths, request/response schemas, or HTTP status codes.
- Those API-level details were therefore designed as an implementation-oriented OpenAPI proposal consistent with the SRS.
- `x-functional-requirement` and `x-functional-requirements` map API operations back to the originating FR IDs.
